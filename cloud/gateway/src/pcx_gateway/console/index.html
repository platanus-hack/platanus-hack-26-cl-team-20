WUI · interfaz de usuario del mundo

La mesa es la interfaz.

WUI le da a tu agente una cámara y un proyector: ve lo que hay sobre la mesa y proyecta botones, guías y respuestas encima de las cosas reales.

Abrir la mesa sin instalar nada

Pégalo en Claude Code o Codex:

  1. 01

    Tu agente lee las instrucciones

    El mensaje lo manda a una página de texto pensada para agentes. Prepara este computador y crea una mesa nueva solo para ti.

  2. 02

    Te abre la mesa

    Te pide tres permisos en el navegador: las cámaras, la pantalla del proyector y el micrófono.

  3. 03

    Se conecta y proyecta

    Se conecta por MCP con la llave de esa mesa, mira lo que hay encima y te saluda proyectando sobre ella.
